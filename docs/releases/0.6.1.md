# 0.6.1

A small release, a few hours after 0.6.0. No code changed: the rule, the command and the engine are 0.6.0's, so cached results carry over and nothing is measured again.

- **The package description** fits npm's limit of 250 characters. npm cut 0.6.0's in the middle of a sentence, on its page and in search.
- **The ESLint peer range** is now `>=9.0.0 <11`, as the README says: ESLint 9 or 10. It had no upper limit.
- **The README's "Quick start with ESLint"** gives the config object that makes ESLint lint and parse `.jsx` files. With the recommended config alone, a project whose config had nothing for JSX got no warning; the lint's summary said so and linked to the fix, which now sits in the quick start:

  ```js
  { files: ["**/*.{js,jsx}"], languageOptions: { parserOptions: { ecmaFeatures: { jsx: true } } } },
  ```

- **Provenance:** this version is published from GitHub Actions with npm provenance. 0.6.0 was published by hand, because npm needs a package to exist before a trusted publisher can be added.

The engine is unchanged: slimdeer 0.3.1, the same files as 0.6.0. [What 0.6.0 brought](https://github.com/lndgalante/oxlint-plugin-slimdeer/blob/main/docs/releases/0.6.0.md)
